# experiments/ — research history

*How* the harness's results were arrived at. The narrative findings (the blog write-ups) live in the
Decision Spine `blog-research` repo; this folder is the repo-local record — pre-registrations,
superseded design notes, and the audits behind the methodology.

- **`loo_preregistration.md`** — the leave-one-out ablation pre-registration: predictions +
  falsifiers, written *before* the run so the results are predictions, not post-hoc stories.
- **`r6-semantic-tests.md`** — a **superseded** design note. It planned an early R6–R11 "semantic
  ladder"; the ladder that shipped is R0–R9 (see `docs/RELIABILITY.md`). Kept for the reasoning.
- **`integrity-audit/`** — the grader-integrity audit that motivated harness v2: the scripts and
  raw data behind the "refusal credited as correct" bug and the diagnostic keyword-echo finding.

Curated *result* evidence (the numbers a write-up cites) lives separately in `results/published/`.
