=== governed catalogue (default view) ===
Governed metrics (call query_metric with these names):
- value_moments: Number of value moments (completed habits) in the period. Raw activity volume — includes all users.
    also called: completed habits, habit completions, activity, engagement events
    group_by / filter dimensions: region, platform, channel, country
    supports filter is_internal=false
    time-filterable (period=…) and grainable (time_grain=week|month|day)
- real_value_moments: Value moments from real users in the period (excludes internal/test accounts). The North Star: this is the metric the tree decomposes into breadth x frequency x depth.
    also called: north star, real value moments, real habit completions
    group_by / filter dimensions: region, platform, channel, country
    supports filter is_internal=false
    time-filterable (period=…) and grainable (time_grain=week|month|day)
- new_signups: Number of user signups in the period (raw — includes all accounts).
    also called: signups, new users, registrations, new accounts
    group_by / filter dimensions: region, channel, platform
    supports filter is_internal=false
    time-filterable (period=…) and grainable (time_grain=week|month|day)
- active_users: Distinct real users with at least one value moment in the period (excludes internal/test accounts).
    also called: active users, actives, engaged users, MAU, WAU
    group_by / filter dimensions: region, platform, channel, country
    supports filter is_internal=false
    time-filterable (period=…) and grainable (time_grain=week|month|day)
- power_users: Distinct real users who logged 5+ value moments in a single day during the period (excludes internal/test).
    also called: power users, superusers, highly engaged users
    group_by / filter dimensions: region, platform, channel, country
    supports filter is_internal=false
    time-filterable (period=…) and grainable (time_grain=week|month|day)
- days_per_user: Average active days per active user in the period (frequency; excludes internal/test).
    also called: frequency, how often, active days per user
    group_by / filter dimensions: region, platform, channel, country
    supports filter is_internal=false
    time-filterable (period=…) and grainable (time_grain=week|month|day)
- moments_per_day: Average value moments per active day (depth; excludes internal/test).
    also called: depth, intensity, moments per active day
