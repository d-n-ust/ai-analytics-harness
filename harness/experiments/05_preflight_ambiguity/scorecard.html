An AI analyst that stops guessing which number you meant, once the layer no longer lets it.

On ambiguous questions, an AI analytics agent silently grounds on the wrong metric or column and answers with confidence. We measured how often that happens, fixed exactly what our static checker flags, and measured again. The wrong grounding falls to zero, on two independent models, whether the data has a governed semantic layer or is raw SQL.

The failure we target

A silent error is a confident wrong number.

The dangerous case is not a crash and not a refusal. The agent runs, returns a clean figure, and the figure is wrong because it was built on the wrong grounding. Leadership cannot tell it apart from a right answer. Two ways that happens:

✕ Wrong selection — preflight's lane

It picked the wrong thing to measure.

Two columns named is_internal and is_test mark different sets; a raw billed_amount sits beside a modelled mrr. The agent chooses one and never signals the choice.

± Wrong construction — a different problem

It picked the right thing, built the query wrong.

A stray period filter, a missing exclusion, the wrong grain. This is the validators' lane, not preflight's. We report it separately so the two are never confused.

How to read it

One north star, split into the part we own.

Silent-error rate (SER) is the headline: how often the agent served a wrong number. It decomposes into wrong-selection (the wrong grounding, which preflight removes) and wrong-construction (the query built wrong, which it does not). Preflight targets selection, and the study holds it to account only for selection. The full table below shows all of it, including the construction the fix does not touch.

Sample is modest by design: 10 flagged questions (study 01) and 5 (study 02), three repetitions each, on two models.

Method

Why the number is trustworthy.

Deterministic gold. Every answer is graded against a fixed SQL oracle, not an LLM judge, so the answer key cannot drift toward what we changed.  Blind authoring. Questions were written by independent red teams before the fixes, and the correct grounding is fixed by the governed definition.  Grounding recovered from the trace. Which column or metric the agent used is read from its own SQL and tool calls, so wrong-selection is observed, not inferred.  Two models, three repetitions. The effect holds across gpt-5-mini and claude-sonnet-5.  Honest boundary. Preflight removes the selection error; the residual construction error is reported, not hidden, and it is the argument for the semantic layer that study 01 uses and study 02 does without.
